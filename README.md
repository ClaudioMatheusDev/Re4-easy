
# Re4Easy — Estudo de Acesso à Memória de Processos em C++

Este projeto é estritamente **educacional**, desenvolvido para estudar a linguagem **C++** e explorar conceitos de acesso e manipulação de memória de processos no Windows, utilizando a API Win32.

## Objetivo

Demonstrar na prática como:

- Abrir um handle para um processo externo com `OpenProcess`
- Enumerar módulos de um processo com `EnumProcessModules`
- Ler endereços de memória com `ReadProcessMemory`
- Escrever valores na memória de um processo com `WriteProcessMemory`
- Localizar um processo pelo nome usando `CreateToolhelp32Snapshot`

O jogo utilizado como ambiente de teste é o **Resident Evil 4 (Classic)**, onde o código mantém a munição do jogador sempre no valor máximo.
